An icon-only control on soft paper material — use for compact toolbar actions (shuffle, save, close). Always pass a `label` for accessibility.

```jsx
<IconButton label="Surprise me"><ShuffleIcon /></IconButton>
<IconButton label="Save look" variant="primary" shape="rounded"><HeartIcon /></IconButton>
```

`shape`: `circle` (default) / `rounded`. `variant`: `surface` (default) / `primary` / `ghost`. `size` is square px (default 56).
